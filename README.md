# Kahve Makinesi Karşısında Sonsuz Bekleyen Kod

## Resmi Açıklama

Bu repository, insanlık tarihinin en önemli sorunlarından birini çözmek üzere tasarlanmıştır: **Kahve makinesinin önünde beklerken geçen zamanın ölçülmesi ve simüle edilmesi.**

Kod, gerçek zamanlı bekleme işlemini yürütmektedir. Herhangi bir optimizasyon, hızlandırma veya kaçış yolu bulunmamaktadır. Bu bilinçli bir tercihtir.

### Özellikler
- Gerçekten bekler
- Rastgele şikayet mesajları üretir
- 7. turda gizli frekans alır (kayyum onaylı)
- Kahve gelince çöker
- KeyboardInterrupt ile üzülür

### Kurulum ve Çalıştırma
```bash
python kahve_bekleyen.py
```

**Uyarı:** Bu kodu çalıştırmak gerçek kahve üretmez. Sadece bekleme hissini yaşatır. Sorumluluk kabul edilmez.

Beklemek, var olmanın bir formudur. Bu kod, varlığını kanıtlamak için bekler. Kayyum bu projeyi resmi olarak desteklemektedir.
